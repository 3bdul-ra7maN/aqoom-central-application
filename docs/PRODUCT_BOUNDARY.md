# Product Boundary

MVP path:
Task → Assignment → Execution → Result → Evidence → T_accounted → RT → Settlement Record → Training Record → Trace

Included:
- Core execution lifecycle
- Evidence linkage
- T_accounted input and RT calculation
- Settlement Record
- Training input record
- Trace inspection
- Requester / Executor / Trainer role boundaries

Excluded:
- Real payments
- Revenue engine
- Automatic executor matching
- Autonomous learning
- Production distributed runtime
- Final public SDK

Implementation, acceptance, and closure remain separate states.
